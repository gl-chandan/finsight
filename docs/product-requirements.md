# FinSight

## Problem

Financial analysts spend significant time manually
reviewing financial statements, annual reports and
management commentary.

## Solution

FinSight provides a conversational AI interface that
combines structured financial analysis with document
retrieval to help analysts perform financial due diligence.

## Core Features

1. Company financial dashboard
2. Financial ratio analysis
3. Annual report ingestion
4. Document RAG
5. Conversational AI analyst
6. SQL-based financial analysis
7. Risk analysis
8. Source citations

## Target User

Financial analysts and consulting analysts.
